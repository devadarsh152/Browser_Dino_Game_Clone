# 2D Chrome Dino Game Remake (Godot 4)

A 2D endless runner remake of the classic browser Dino Game built in **Godot 4** using **GDScript**. Designed to demonstrate procedural obstacle generation, dynamic speed progression, and infinite background scrolling.


## 🕹️ Key Features & Implementation Details
* **Procedural Spawner:** Programmed dynamic obstacle spawning using `Timer` nodes with randomized intervals and object pooling patterns.
* **Dynamic Speed Scaling:** Implemented game difficulty scaling by gradually increasing scroll velocity over time.
* **Parallax Scrolling:** Configured background layers to create smooth layered depth for endless movement.
* **Score & Persistence:** Built real-time score tracking and local state resets upon collision detection.

## 🛠️ Built With
* **Engine:** Godot Engine 4.x
* **Language:** GDScript
